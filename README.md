# Практична робота №2
## Аналіз авторських прав на програмний код

**Мета:** навчитися розрізняти власну реалізацію, сторонній ліцензований код та код із невизначеними правами використання.

**Ситуація:** розробник створює комерційний вебзастосунок, використовуючи власні функції, код із GitHub і матеріал від іншого розробника.

У цьому навчальному проєкті реалізовано вебсторінку перегляду завдання. Сервер приймає назву і відображає її як текст HTML за допомогою сторонньої функції `escape-html`. Приклад демонструє аналіз ліцензій, а не готовність до промислової експлуатації.

## 1 Структура репозиторію

Репозиторій містить рівно п’ять файлів:

```text
server.cjs   — власна серверна реалізація
index.html   — власна сторінка та стилі
vendor.cjs   — сторонній код escape-html
LICENSE      — незмінений текст MIT License стороннього коду
README.md    — походження файлів, перевірка ліцензії та звіт
```

Власна реалізація означає код, створений для цього завдання, а не скопійований із зовнішнього репозиторію. `server.cjs`, `index.html` і цей звіт підготовлено за допомогою Codex. Це не твердження, що студент особисто написав їх без допомоги або що весь згенерований матеріал автоматично охороняється авторським правом.

## 2 Запуск

Потрібен Node.js з підтримкою модулів `node:http`, `node:fs` і `node:path`. Встановлення npm-залежностей не потрібне.

```sh
node server.cjs
```

Відкрийте http://127.0.0.1:3000. Для зупинки натисніть Ctrl+C.

Спробуйте назву `Підготувати звіт`, а потім `<script>alert(1)</script>`. Другий рядок має відобразитися як текст і не виконуватися як JavaScript. Функція екранує спеціальні символи HTML; її не слід застосовувати як універсальний захист для URL, CSS або JavaScript.

Назва передається параметром URL і не зберігається застосунком. Не вводьте секретні дані. Сервер доступний лише локально.

## 5 Умовний код від іншого розробника

**Це навчальна ситуація, а не опис реально отриманого файла.** Інший розробник надсилає функцію `calculateDiscount`, але не додає ліцензії, договору або дозволу правовласника.

Передання файла саме по собі не підтверджує право включати код у комерційний продукт. Відправник може не бути власником майнових прав: наприклад, функцію створено для роботодавця або скопійовано з іншого проєкту.

Потрібно встановити походження коду, належність майнових прав та отримати документований дозвіл на необхідне використання, зміну й поширення. До цього моменту статус — **права невизначені; використання не погоджено**. Функцію не включено до репозиторію чи застосунку. Альтернатива — незалежно реалізувати потрібну функціональність без копіювання цього коду.

Так само публічна доступність GitHub-репозиторію без ліцензії не є загальним дозволом вбудовувати його код у комерційний продукт. Можливість перегляду або fork у межах GitHub не дорівнює такому дозволу.

## 6 Короткий звіт про потенційні порушення

| Потенційна проблема | Чому виникає ризик | Рішення у роботі |
|---|---|---|
| Копіювання коду з GitHub без ліцензії | Немає підтвердженого дозволу на потрібне використання | Такий код не включено; вибрано компонент із перевіреною MIT License |
| Видалення повідомлень про права | Порушення умови MIT про збереження повідомлень і дозволу | Заголовок `vendor.cjs` та повний файл `LICENSE` збережено |
| Отримання коду від знайомого без перевірки | Знайомий може не мати прав або не надати достатнього дозволу | Умовний фрагмент виключено до підтвердження прав |
| Приписування собі стороннього авторства | Хибне зазначення походження та можливе порушення прав автора | Вказано джерело, commit та імена з повідомлень про права |
| Помилкове застосування MIT до всього проєкту | Ліцензія стороннього компонента не визначає автоматично права на власні файли | Межі дії LICENSE прямо зазначено |
| Невраховані права роботодавця або замовника | Власноручне написання коду не завжди означає належність усіх майнових прав розробнику | Для реального комерційного випуску потрібно перевірити застосовні договори |

Неліцензований код і умовний фрагмент від іншого розробника не включено. За перевіреними умовами MIT перешкод для комерційного використання `escape-html` не виявлено; права на власну частину й інші можливі правові обмеження оцінюються окремо.
